# kitty-config

Personal kitty configuration. Keymaps are the `map` lines in `kitty.conf`.

## Keyboard shortcuts

The Logseq page `/home/andrzej/Documents/Notes/pages/kitty configuration.md` describes every keyboard shortcut
this configuration defines.

When you add, change or remove a shortcut in `kitty.conf` or in a script it binds, update that page in the same
change, without waiting to be asked. Keep the page's outline format: one bullet per shortcut, grouped by prefix,
tabs, clipboard, with the `map` line beneath it.
